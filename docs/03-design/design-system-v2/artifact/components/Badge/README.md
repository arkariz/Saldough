# Badge

Badge status dan tag kategori. Bentuk ikut acuan (KT-DS4): sudut 6px, huruf **Space Mono Bold** 11px (`pixelCaption`) — bukan pil. Yang berbentuk pil hanya chip pilihan (filter) dan **status pill**.

**Nada badge:** `income` (sage, "84% SEHAT"), `warm` (sampanye, kategori hidup sehari-hari), `warning`, netral (surface-sunken, "74% TERPAKAI"), `category` (tag kategori tanpa bingkai).
**Status pill** `ds-pill`: titik hijau 6px (berdenyut di aplikasi) + label kapital, isi `surface-sunken`.

Teks badge pendek, satu baris. Warna tidak pernah menjadi satu-satunya pembawa arti.

**Flutter:** `DsBadge`, `DsStatusPill`.
