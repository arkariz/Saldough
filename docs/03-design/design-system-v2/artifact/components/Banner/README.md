# Banner

Banner satu baris di atas konten (`DsInlineBanner`). Tingkat `card`, sudut 16, padding 12. Kiri icon tile `sm` (`solid` untuk misi), tengah eyebrow Space Mono kapital `action-primary` + satu baris `bodySm` yang terpotong, kanan tombol `compact`. Varian `warning` dan `error` memakai kontainernya. Satu banner aktif per layar; bisa ditutup bila tidak kritis.

**Flutter:** `DsInlineBanner`.
