# Checkbox

Checkbox 16px, sudut 4, bingkai `outline-strong` (ikut spek, KT-DS1). Terpilih: isi `action-primary` dengan centang putih. Area sentuh baris penuh, minimal 44px. Radio dan switch memakai hijau yang sama lewat `DsTheme`.

**Flutter:** `Checkbox`/`Radio`/`Switch` Material yang digayakan `DsTheme`.
