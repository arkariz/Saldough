# MascotCard

Kartu mood maskot di Beranda. Tingkat `card`, sudut 16, padding 14. Kiri: icon tile `lg` berisi tanuki clay dengan titik status 8px bercincin. Kanan: baris judul (Space Mono 12 + badge `income`), meter `health`, keterangan `bodySm` `text-secondary`.

Bisa diketuk (skala 0,99). Maskot bernapas pelan (`DsIdleMotion`), berhenti saat gerak dikurangi. Tidak ada teks di dalam komponen; judul dan keterangan datang dari pemanggil.

**Flutter:** `DsMascotCard`.
