# NavBar

Navigasi bawah, tinggi 64: latar `surface-canvas` 90% + blur, garis atas `outline-subtle`. Empat tab (Beranda, Riwayat, Rencana, Dompet) mengapit tombol **Catat** di tengah (44px, sudut 16, `action-primary`, naik 20px, label "Catat"). Tab: ikon 21px + label Space Mono 11px (KT-DS3, acuan 10px). Aktif `action-primary` dengan titik 6px di bawah; lain `text-secondary`. Tekan lama Catat membuka suara.

Selisih: acuan 3 tab + Catat; aplikasi 4 tab.

**Flutter:** `DsNavBar`, `DsNavItem`.
