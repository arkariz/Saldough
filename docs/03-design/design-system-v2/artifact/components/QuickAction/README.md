# QuickAction

Tile aksi cepat: kartu tingkat `card` bersudut 16, padding 12×4; icon tile `md` clay di atas label Space Mono 11 kapital. Disusun grid 4 kolom jarak 8; ditekan skala 0,95.

Label memakai kosakata mencatat: "Catat transfer" (bukan "Kirim"), "Catat pemasukan", "Laporan", "Scan struk" (KT-DS8). Maksimal empat tile.

**Flutter:** `DsQuickActionTile`.
