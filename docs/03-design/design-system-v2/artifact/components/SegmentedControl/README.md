# SegmentedControl

Kontrol segmen (Hari/Minggu/Bulan/Tahun): track `surface-sunken`, tiap segmen bersudut 6, segmen terpilih `surface-card` berbingkai `outline-subtle` dengan teks `text-primary`. Maksimal 4 segmen; label satu kata.

**Flutter:** `SegmentedButton` Material yang digayakan `DsTheme`.
