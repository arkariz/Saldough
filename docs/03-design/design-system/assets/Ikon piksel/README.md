# Ikon piksel

Ikon milik Tanukonomy, digambar di grid 32×32 dengan `shape-rendering="crispEdges"`, berwarna penuh (tidak bisa diwarnai ulang lewat CSS). Tampilkan 32px atau 64px saja, di tile `surface-2` (komponen IconTile, varian piksel). Pemetaan ke kategori dan dompet ada di README bagian Ikon.

- `category_*.svg` — kategori pengeluaran.
- `wallet_*.svg`, `wallets.svg` — jenis dompet.
- `income.svg`, `expense.svg`, `transfer.svg` — jenis transaksi.
- `freelance.svg`, `worklog.svg`, `hourly_rate.svg`, `invoice.svg`, `pending.svg`, `paid.svg`, `work_completed.svg` — freelance.
- `budget.svg`, `over_budget.svg`, `check.svg`, `locked.svg`, `empty.svg` — status.
- `home.svg`, `transactions.svg`, `record.svg`, `search.svg`, `filter.svg`, `calendar.svg` — dari navigasi lama; tidak dipakai di navigasi baru (navigasi memakai Material Symbols).
