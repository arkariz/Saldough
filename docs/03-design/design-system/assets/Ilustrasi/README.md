# Ilustrasi

Ilustrasi piksel tanuki juru catat (topi jerami, syal merah). Tampilkan dengan `image-rendering: pixelated` (Flutter: `FilterQuality.none`), latar transparan, di atas `bg` atau `surface`.

- `mascot_head.png` — kepala tanuki, 288×226. Untuk kartu saldo (lebar 96px), layar akun, dan Freelance kosong.
- `onboarding_1.png` — tanuki menulis di buku catatan. Riwayat kosong, orientasi langkah mencatat.
- `onboarding_2.png` — tanuki di atas dompet, dompet koin, toples tabungan, dan ponsel yang saling terhubung. Dompet kosong.
- `onboarding_3.png` — tanuki dengan jalur ikon kategori menuju tombol tambah. Orientasi kategori dan Catat.
- `onboarding_4.png` — tanuki di depan papan anggaran. Anggaran kosong.
- `onboarding_5.png` — tanuki di dalam dompet besar, jalan batu menuju matahari terbit. Beranda pertama kali.

Jangan menaruh ilustrasi di kartu data, di samping angka, atau di bar navigasi.
