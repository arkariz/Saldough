# Badge

Satu atau dua kata status di samping isi.

**Nada:** netral (jenis, periode: "Bulanan"), `positive` ("Aman", "Diterima"), `warning` ("Perlu dicek", "Tertunda", "Hampir habis"), `danger` ("Lewat Rp36.000"), `info` ("Transfer"), `brand` ("Pola bawaan").

**Aturan**
- Huruf biasa, bukan kapital semua. Paling banyak tiga kata.
- Ikon 16px opsional di depan untuk status yang butuh perhatian.
- Satu badge per baris atau kartu. Jangan menumpuk badge jenis dan status sekaligus.

**Disediakan pemakai:** teks, nada, ikon opsional.
