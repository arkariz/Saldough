# Banner

Pesan satu kalimat di dalam halaman yang meminta perhatian, dengan satu tindakan.

**Nada:** `warning` (perlu tindakan: transaksi dari notifikasi menunggu dicek), `info` (keterangan: pencarian hanya di bulan ini), `danger` (masalah: anggaran lewat), `positive` (hasil: pembayaran dicatat diterima).

**Aturan**
- Paling banyak satu banner per layar, di bawah angka utama.
- Satu kalimat + satu tindakan (`tk-btn--sm` `--on-soft`). Tanpa tombol tutup kecuali pesan bisa diabaikan selamanya.
- Bukan tempat aturan atau penjelasan cara kerja.

**Disediakan pemakai:** nada, ikon, teks, tindakan opsional.
