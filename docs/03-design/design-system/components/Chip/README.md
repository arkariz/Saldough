# Chip

Pilihan cepat berbentuk pil: kategori di Catat dan filter di Riwayat.

**Varian**
- Pilihan kategori (satu terpilih): ikon kategori + nama; terpilih berubah jadi `brand-soft` dengan ikon `check`.
- Filter (Riwayat): label + jumlah ("Pengeluaran 24"); di atas `bg` pakai `--on-bg` (latar `surface`).

**Aturan**
- Urutkan kategori dari yang paling sering dipakai; chip terakhir "Semua kategori" membuka sheet daftar lengkap.
- Satu baris yang bisa digeser, jangan membungkus jadi tiga baris.
- Tinggi 36px, area sentuh 48px.

**Disediakan pemakai:** label, ikon, status terpilih, handler.
