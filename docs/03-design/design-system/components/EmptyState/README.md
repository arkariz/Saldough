# EmptyState

Keadaan kosong: ilustrasi tanuki, apa yang belum ada, manfaatnya, dan satu tindakan untuk mengisinya.

**Aturan**
- Ilustrasi dari grup Ilustrasi, lebar 120–160px, `image-rendering: pixelated`.
- Judul menyebut apa yang belum ada ("Belum ada dompet"). Isi satu kalimat manfaat, bukan aturan. Satu tombol `primary`.
- Kosong karena filter: tanpa ilustrasi, judul "Tidak ada yang cocok", tombol `text` "Hapus filter".
- Di Beranda pertama kali, ganti dengan daftar langkah (lihat Pola layar).

**Ilustrasi per layar:** Beranda pertama kali `onboarding_5.png`, Dompet `onboarding_2.png`, Anggaran `onboarding_4.png`, Riwayat `onboarding_1.png`, orientasi kategori `onboarding_3.png`, Freelance `mascot_head.png`.

**Disediakan pemakai:** ilustrasi, judul, isi, tindakan.
