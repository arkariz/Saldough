# Skeleton

Bentuk abu-abu sementara yang meniru isi asli selama data dimuat.

**Aturan**
- Tiru tata letak asli: tile 40px, dua garis teks, nominal di kanan. Jangan pakai pemutar di tengah layar.
- Latar `surface-2`, berdenyut pelan 1,4 detik; tanpa animasi saat kurangi gerakan aktif.
- Data lokal biasanya siap di bawah 300ms: tampilkan skeleton hanya bila memuat lebih lama dari itu supaya layar tidak berkedip.

**Disediakan pemakai:** jumlah baris tiruan.
