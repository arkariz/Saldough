# Snackbar

Kabar singkat setelah tindakan, muncul di atas navigasi bawah dan hilang sendiri.

**Aturan**
- Kalimat lampau pendek: "Pengeluaran tercatat.", "Catatan dihapus.", "Tangkapan diabaikan."
- Tindakan yang bisa dibalik selalu punya "Urungkan" (`inverse-brand`); snackbar bertahan 6 detik bila ada aksi, 4 detik bila tidak.
- Satu snackbar sekaligus; yang baru menggantikan yang lama.
- Galat yang butuh perbaikan tidak ditaruh di snackbar, tetapi di dekat kolomnya atau sebagai banner.

**Disediakan pemakai:** teks, aksi opsional.
